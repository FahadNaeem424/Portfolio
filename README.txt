STATIC PORTFOLIO BUILD

Open index.html directly, or upload the contents of this folder to any static host.

The original PHP contact handler is not available in a static site. The contact form
validates in the browser and opens the visitor's email app with a prepared message.

Before publishing, replace the sample email, phone number, profile links, project URLs,
and other placeholder content inherited from the PHP source.

After choosing a live domain, update canonical/OG URLs and sitemap.xml to absolute URLs.
